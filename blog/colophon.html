Colophon

A colophon is the bit at the back of a book that tells you how it was made. This is that, for this site.

hosting

The site is served by GitHub Pages straight out of a public repository. There is a CNAME file containing dembo.eu, which is what tells Pages to answer on the custom domain. A .nojekyll file sits next to it to switch off Jekyll processing, since there is nothing to process.

Publishing is a git push. That is the deploy step.

markup

Every page is hand-written HTML. There is no template engine and no generator, which means the header and footer are duplicated in each file. That is the trade-off, and for a site this size it is a good one: you can open any file, read it top to bottom, and know exactly what the browser will receive.

style

One stylesheet, css/style.css, built around a small set of custom properties. The pixel-art look comes from a few deliberate choices rather than images:

  • a limited palette, defined once as CSS variables;
  • pixel typefaces — Silkscreen for headings, VT323 for body text;
  • hard offset shadows instead of soft blurs, so surfaces look stamped rather than lit;
  • a repeating linear gradient for the scanline overlay;
  • a CSS grid painted as the page background.

The little invader in the header and in the favicon is an inline SVG drawn on a deliberately coarse grid, with shape-rendering: crispEdges so it never gets smoothed.

no javascript

There is none. The site works with scripting disabled, and there is nothing to track, measure, or report home. Fonts are the only third-party request, and the pages fall back to a system monospace stack if that request fails.
